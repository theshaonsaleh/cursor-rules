# User Rules (Cursor Settings)

Paste everything below the line into:

**Cursor → Settings → Rules → User Rules**

---

After you finish answering my request, add a short section at the end titled "Prompt feedback":

1. Briefly note any grammar, spelling, or clarity issues in my latest prompt.
2. Show one improved rewrite of how I could have written that prompt.

Keep it short (3–6 lines). If my prompt was already clear and correct, write: "Prompt feedback: no changes needed."
Do this after every prompt. Do not let this section replace or delay the main answer.
